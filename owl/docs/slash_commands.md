# Slash commands

In owl's interactive mode, type `/` in the composer to browse the available commands, including your custom prompts. The main ones: `/model`, `/approvals`, `/permissions`, `/status`, `/mcp`, `/skills`, `/review`, `/compact`, `/diff`, `/init`, `/new`, `/resume`, `/fork`, `/feedback`, `/quit`.

There is no login or logout command: owl connects through `~/.owl/config.toml` (see [docs/authentication.md](authentication.md)).
