# Owl

A terminal agent for a self-hosted [Open WebUI](https://github.com/open-webui/open-webui) server: a fork of
OpenAI's open-source [Codex CLI](https://github.com/openai/codex) (Rust, Apache-2.0) retargeted to the
OpenAI-compatible API that Open WebUI serves. No account, no plan: it talks only to the server you configure.

- [`owl/`](owl/): the fork itself. Start with [`owl/README.md`](owl/README.md) for install and use;
  [`owl/LICENSE`](owl/LICENSE) and [`owl/NOTICE`](owl/NOTICE) carry the upstream license and notices.
- [`index.html`](index.html): a page showing Owl's real screens.
